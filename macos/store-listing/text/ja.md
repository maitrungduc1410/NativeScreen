# Japanese

## Subtitle

画面収録とデモ動画の編集

## Promotional Text

画面を一度収録するだけで、デモ動画が完成。自動ズーム、なめらかなカーソル、字幕、マルチトラックのタイムライン。無料でオープンソース、すべて Mac の中で完結します。

## Keywords

画面録画,画面収録,動画編集,デモ,チュートリアル,字幕,ズーム,カーソル

## Description

Native Screen は、ふつうの画面収録を洗練されたデモ動画に仕上げます。クリックを追うズーム、なめらかに動くカーソル、字幕、背景、そして細かく調整したいときの本格的なマルチトラックタイムライン。すべてお使いの Mac の中で動きます。

あなたを追うズーム
クリックや入力が自動でズームになります。位置を動かしたり、倍率を変えたり、一点だけを拡大するルーペに切り替えたりできます。

すべるように動くカーソル
ぶれた軌跡はなめらかに補正され、収録後でもカーソルのサイズやスタイルを変更できます。クリックには控えめな波紋が付きます。

まねしやすいショートカット
押したキーボードショートカットがキーキャップとして動画に表示されるので、見る人が同じ操作を再現できます。

話しながら描く
収録中にキーを押すと、ペン、蛍光ペン、矢印、四角形で画面に描けます。描いた線はすべて注釈としてエディタに入り、あとから変更できます。

自分で描かれていく注釈
テキスト、矢印、図形、画像をそれぞれのトラックに追加できます。ちょうどよいタイミングで描かれ、フェードアウトします。

カメラは思いどおりに
自分を画面の隅や横並びで表示したり、背景から切り抜いたりできます。部屋をぼかしたり写真に差し替えたり、動いても顔についてくるステッカーを付けたりもできます。

言葉を編集すると動画も編集される
字幕は Mac の中で、あなたの言語で作られます。書き起こしがそのままエディタに。文を消せばその部分がカットされ、つなぎ言葉や長い間もまとめて取り除けます。

一度の収録で、どの形にも
横長、正方形、縦長をいつでも切り替えられます。ズームは狙い直され、字幕は読みやすい位置に移動します。

必要なだけトラックを
種類ごとに専用のトラックがあり、さらに追加できます。重なり合う 2 つのぼかし、2 人の話者の字幕、ショートカット専用のレーンなど。

プライバシーを第一に
収録、字幕、機密データの検出、書き出しはすべて Mac の中で行われます。アカウント不要、アップロードなし、トラッキングなし。

クラッシュしても安心
収録は少しずつ書き込まれるので、アプリが落ちてもバッテリーが切れても、テイクは失われません。

オープンなフォーマット
プロジェクトはドキュメント付きの JSON フォルダで、書き出しは標準の MP4、ProRes、GIF です。

ずっと無料
試用期間も有料プランも透かしもありません。Native Screen はオープンソースです。役に立ったら、リポジトリにスターを付けるか修正を送ってください。
