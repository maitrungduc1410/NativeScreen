# Chinese (Traditional)

## Subtitle

螢幕錄影與示範影片剪輯

## Promotional Text

錄一次螢幕，就得到一支完成的示範影片：自動縮放、滑順游標、字幕和多軌時間軸。免費開源，所有內容都留在你的 Mac 上。

## Keywords

螢幕錄影,錄影,影片剪輯,示範,教學,字幕,縮放,游標,錄屏

## Description

Native Screen 能把一般的螢幕錄影變成精緻的示範影片：跟著點擊的縮放、滑順移動的游標、字幕、背景，需要精細控制時還有真正的多軌時間軸。一切都在你的 Mac 上執行。

跟著你的縮放
點擊和打字會自動變成縮放。你可以移動它們、調整縮放深度，或改用放大鏡，只放大一個位置。

滑順的游標
抖動的軌跡會被修順，錄影後還能調整游標大小或樣式，點擊時會出現輕柔的漣漪。

看得懂的快速鍵
你按下的鍵盤快速鍵會以按鍵圖示出現在影片中，觀眾可以照著操作。

邊講邊畫
錄影時按一個鍵，就能用畫筆、螢光筆、箭頭或方框在螢幕上繪製。每一筆都會成為編輯器裡的註解，之後仍可修改。

自動繪入的註解
在獨立軌道上加入文字、箭頭、形狀和圖片。它們會準時繪入、淡出。

隨心使用相機
把自己放在角落、並排顯示，或從背景中去背。可以模糊房間或換成一張照片，還能加上隨臉移動的貼紙。

改文字就是改影片
字幕在你的 Mac 上產生，支援你的語言。逐字稿就是編輯器：刪掉一句話就剪掉那一段，也能一次清除所有贅詞和長停頓。

一次錄影，各種比例
隨時在橫向、方形和直向之間切換。縮放會重新對準，字幕也會移動位置以保持清楚易讀。

軌道數量隨內容而定
每類內容都有自己的軌道，還能再增加：兩個互相重疊的模糊區域、兩位講者的字幕、獨立一條快速鍵軌道。

隱私優先
錄影、字幕、敏感資料偵測和輸出都在你的 Mac 上完成。不需帳號，不上傳，不追蹤。

不怕當機
錄影內容會邊錄邊分段寫入，即使 App 當機或電池沒電，也不會遺失這一段。

開放格式
專案是附有文件說明的 JSON 資料夾，輸出為標準的 MP4、ProRes 或 GIF。

永久免費
沒有試用期，沒有付費方案，沒有浮水印。Native Screen 是開源軟體。如果它對你有幫助，歡迎替儲存庫按個 Star 或提交修正。
