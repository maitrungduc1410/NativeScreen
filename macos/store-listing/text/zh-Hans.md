# Chinese (Simplified)

## Subtitle

录屏与演示视频剪辑

## Promotional Text

录一次屏，就得到一段完成的演示视频：自动缩放、顺滑光标、字幕和多轨时间线。免费开源，所有内容都留在你的 Mac 上。

## Keywords

录屏,屏幕录制,视频剪辑,演示,教程,字幕,缩放,光标,录屏软件

## Description

Native Screen 能把普通的屏幕录制变成精致的演示视频：跟随点击的缩放、顺滑移动的光标、字幕、背景，需要精细控制时还有真正的多轨时间线。一切都在你的 Mac 上运行。

跟着你走的缩放
点击和输入会自动变成缩放。你可以移动它们、调整缩放深度，或者换成放大镜，只放大一个位置。

顺滑滑动的光标
抖动的轨迹会被平滑处理，录制后还能调整光标大小或样式，点击时会出现轻柔的波纹。

看得懂的快捷键
你按下的键盘快捷键会以按键图标出现在视频里，观众可以照着操作。

边讲边画
录制时按一个键，就能用画笔、荧光笔、箭头或方框在屏幕上绘制。每一笔都会作为标注进入编辑器，之后仍可修改。

自动绘入的标注
在独立轨道上添加文字、箭头、形状和图片。它们会准时绘入、淡出。

随心使用摄像头
把自己放在角落、并排显示，或从背景中抠出来。可以虚化房间或换成一张照片，还能加一个随脸移动的贴纸。

改文字就是改视频
字幕在你的 Mac 上生成，支持你的语言。文字稿就是编辑器：删掉一句话就剪掉那一段，也可以一次清除所有口头禅和长停顿。

一次录制，各种画幅
随时在横屏、方形和竖屏之间切换。缩放会重新对准，字幕也会移动位置以保持清晰可读。

轨道数量随内容而定
每类内容都有自己的轨道，还能继续添加：两个互相重叠的模糊区域、两位讲者的字幕、单独一条快捷键轨道。

隐私优先
录制、字幕、敏感信息识别和导出都在你的 Mac 上完成。无需账号，不上传，不追踪。

不怕崩溃
录制内容会边录边分段写入，即使应用崩溃或电池耗尽，也不会丢失这一段。

开放格式
项目是带有文档说明的 JSON 文件夹，导出为标准的 MP4、ProRes 或 GIF。

永久免费
没有试用期，没有付费方案，没有水印。Native Screen 是开源软件。如果它对你有帮助，欢迎给仓库点个 Star 或提交修复。
